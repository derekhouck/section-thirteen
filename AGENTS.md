# Development Commands

- Run the local development server: `bundle exec jekyll serve`
- Install dependencies: `bundle install`
- Note: Changes to `_config.yml` require a server restart.

# Project Structure

- `_posts/`: Blog posts (Markdown files with front matter).
- `_layouts/`: Page templates.
- `_includes/`: Reusable HTML snippets.
- `assets/`: Images and other static assets.
- `superfan/`: Content related to the "Superfan" short film.

# Technical Details

- Framework: Jekyll (Static Site Generator)
- Theme: `minima`
- Language: Ruby (via Bundler)
- Deployment: Likely GitHub Pages (given the Jekyll setup), but check repo settings for specifics.
